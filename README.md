# Circle — Truth or Dare

Local-first party game. Add names in the room, pick Friendly or Adult, then take turns with Truth, Dare, or a bottle spin.

- English and Russian
- Male / female avatars per player
- Custom prompts
- Runs entirely in the browser (no accounts)

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL.

```bash
npm run typecheck
npm run build
```

## Play

1. Choose language (EN / RU)
2. Tap fox or bunny, type a name, add players
3. Pick Friendly or Adult
4. Start — Truth, Dare, or Go now to spin
